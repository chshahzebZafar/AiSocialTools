## 🎯 Style Guidelines for All Images

### Technical Requirements:
- **Dimensions:** Exactly 1200 x 630 pixels
- **Aspect Ratio:** 1.91:1 (Facebook/Linkedin standard)
- **Format:** JPG or PNG
- **File Size:** Under 1MB (optimize for web)
- **Text Size:** Minimum 60px for main text, 40px for subtitles
- **Safe Zone:** Keep important content within 1120x550px (40px margin)

### Design Principles:
1. **High Contrast:** Text must be easily readable
2. **Brand Colors:** Use blue (#3B82F6), purple (#9333EA), pink (#EC4899)
3. **Minimalism:** Don't overcrowd - less is more
4. **Professional:** Trustworthy and modern appearance
5. **Versatile:** Should work across different social platforms

### Text Hierarchy:
- **Primary Text:** Large, bold, white (60-80px)
- **Secondary Text:** Medium, lighter white/gray (40-50px)
- **Tertiary Text:** Small, subtle (24-30px)

## 🚀 Using These Prompts

### With DALL-E (ChatGPT):
1. Copy the prompt you want
2. Paste into ChatGPT with DALL-E enabled
3. Specify: "Create this as a 1200x630 pixel image"
4. Download and optimize the result

### With Midjourney:
1. Copy the prompt
2. Add: `--ar 1.91:1 --style raw --v 6`
3. Use `/imagine` command
4. Upscale the best result

### With Stable Diffusion:
1. Use the prompt
2. Set dimensions: 1200x630
3. Use a professional model (e.g., Realistic Vision)
4. Adjust guidance scale: 7-9

### With Canva:
1. Use Canva's AI image generator
2. Enter the prompt
3. Set custom size: 1200x630
4. Add text overlays manually if needed

### With Figma/Design Tools:
1. Create 1200x630px artboard
2. Use the prompt as design brief
3. Design manually following the specifications
4. Export as JPG optimized for web

## 📝 Customization Tips

### For Different Brand Colors:
Replace the color codes in the prompts:
- Blue: `#3B82F6` → Your brand blue
- Purple: `#9333EA` → Your brand purple
- Pink: `#EC4899` → Your brand accent color

### For Different Text:
- Replace "Social Media Tools" with your brand name
- Adjust subtitles to match your messaging
- Keep text concise (social media previews are small)

### For Different Styles:
- **Minimalist:** Remove decorative elements, focus on typography
- **Bold:** Increase contrast, use brighter colors
- **Professional:** Use more muted colors, subtle gradients
- **Playful:** Add more icons, use brighter colors
